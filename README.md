## Описание проекта

Цель проекта — разработать алгоритм машинного обучения для предсказания целевых сессий пользователей.

Ключевые особенности:
1. **Сильный дисбаланс классов:** Доля целевого класса составляет порядка 8% от общего количества наблюдений.
2. **Специфика целевой метрики:** Оценка производится по метрике **Precision@Recall >= 0.70**.
3. **Временная структура логов:** События представляют собой временные ряды, что требует строгого исключения утечек данных из будущего.


## Мой подход к решению

### 1. Фильтрация событий по интервалу
Из общего массива событий (`events.csv.gz`) отбираются только те действия, которые попадают в окно наблюдения `[window_start_ts, window_end_ts)` для каждого конкретного `cookie_id`.

### 2. Инжиниринг поведенческих признаков (42 фичи)
* **Анализ временных интервалов (Micro-timing):** паузы между кликами (`time_diff`), счётчики мгновенных и аномально быстрых переходов.
* **Анализ курсора (`pointer_x`, `pointer_y`):** дисперсия (`std`) и число уникальных координат.
* **Разнообразие сессии:** количество уникальных объявлений, категорий, локаций, платформ и User-Agent.
* **Распределение событий и платформ:** Pivot-агрегации типов действий.

### 3. Моделирование и валидация
* **Схема валидации:** Временное разделение по порогу `window_start_ts >= 2026-04-17`.
* **Выбор алгоритма:** **`HistGradientBoostingClassifier`** с `class_weight="balanced"` и L2-регуляризацией .
